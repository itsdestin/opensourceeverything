# Community features: everything Destin has decided so far (Oct 25 – Nov 3)

WHY this file: on Nov 3 the step-2 deck (`decisions/community-1.questions.json`) confused Destin, because earlier
rounds had already decided parts of it. Three agents read every deck answer, the planning docs and his own messages.
This is the result, so later sessions start from it rather than re-asking. Quotes are his, verbatim.
